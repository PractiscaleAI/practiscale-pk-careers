# Sources and validation scope

The supplied original brand files and the user's approved revisions establish brand authority. Edition 1.4 clarifies that colors, type roles, logo protection, and CTA identity are established while website layouts remain pending. A selected reference controls composition; it does not silently replace the identity.

## Accessibility and implementation references

- W3C: [WCAG 2.2](https://www.w3.org/TR/WCAG22/). Text contrast 1.4.3; non-text contrast 1.4.11; visible focus 2.4.7; focus not obscured 2.4.11; target size 2.5.8.
- MDN: [prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion).
- web.dev: [Web Vitals](https://web.dev/articles/vitals). Performance targets are not measured results for an unbuilt site.

## Voice

- Nielsen Norman Group: [The Four Dimensions of Tone of Voice](https://www.nngroup.com/articles/tone-of-voice-dimensions/).
- Mailchimp: [Voice and Tone](https://styleguide.mailchimp.com/voice-and-tone/).

## Assets and licenses

- Google Fonts: [source repository](https://github.com/google/fonts). Sora, Manrope, JetBrains Mono, and Noto Nastaliq Urdu; bundled SIL Open Font License texts.
- [Lucide](https://lucide.dev): ISC icon license. Use original SVG artwork, not a mixed or invented icon set.
- Meta: [WhatsApp brand resources](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/). Use official artwork; no implied endorsement. Verify any production destination.

## What was checked

The package checks cover current source consistency, internal file links, JSON/CSS generation, declared CSS variables, asset identity, fonts, documented contrast, and local component fixture behavior. PDF export is followed by page rendering and visual review. Reports identify the exact files and hashes.

No audience statistic, platform size, renderer version, or speculative technology stack is retained as a current requirement. External references are retained reading; this update does not claim a fresh audit of every external page. Sources and fixture checks do not certify a future layout, live website, company claim, printer proof, or full assistive-technology accessibility.
